# Refresca-T — Página web

Archivos generados:

- `index.html` — Página principal con 5 apartados (Inicio, Acerca de, Galería, Contacto, Fuentes)
- `css/styles.css` — Estilos básicos

Instrucciones:

1. Coloca el logo adjunto en la carpeta raíz como `logo.png`.
2. Añade las imágenes de la galería en `images/` como `drink1.jpg`, `drink2.jpg`, `drink3.jpg`.
3. Añade el icono de Instagram en `icons/instagram.png`.
4. Abre `index.html` en el navegador para ver la página.
